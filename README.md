# Check Mod

Teleport to players in Spectator mode with /check and /uncheck commands.

## Features

- Teleport to players in Spectator mode with `/check <playername>`
- Return to original position with `/uncheck`

## Requirements

- Minecraft 1.21.4
- Fabric Loader 0.15.7 or higher
- Fabric API 0.96.1 or higher

## Installation

1. Download the mod JAR file from the [releases page](https://github.com/EnderDevelopment/check-mod/releases).
2. Place the JAR file in your `mods` folder.
3. Launch Minecraft with Fabric.

## Usage

### Commands

| Command | Description |
|---------|-------------|
| `/check <playername>` | Teleports you to the specified player in Spectator mode. |
| `/uncheck` | Returns you to your original position and game mode. |

### Permissions

This mod does not require any special permissions.
